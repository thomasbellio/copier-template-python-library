# Troubleshooting log

Non-obvious bugs and their causes. Search this file for an error message before debugging.

Add an entry only when the cause was not apparent from the error, or the problem could recur.
Remove entries that describe code which no longer exists.

## Entry format

### <short title> (YYYY-MM-DD)

- **Symptom:** the exact error text or observed behaviour
- **Cause:** the root cause, in one or two sentences
- **Fix:** what was changed, with the regression test's name
- **Recognise it by:** how to tell this problem from similar ones
